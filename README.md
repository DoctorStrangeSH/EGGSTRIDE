# EGGSTRIDE

Яркая игра Roblox про забеги за яйцами на парящих островах. Чем выше скорость, тем дальше можно забежать за 25 секунд и вернуться к инкубатору. Яйцо замедляет бег, поэтому обратный путь стоит учитывать заранее. В каждом раунде биомы получают случайное яйцо из собственного пула. Редкость и вид питомца разыгрываются при вылуплении, а способность яйца и шанс редкого питомца видны заранее. В Луговом биоме яйцо помогает вырастить временный мост домой.

## Что определяет забег

Игрок выбирает дальность вылазки с учётом скорости, таймера и веса яйца. После обучения эту систему расширят ветровые тропы: широкий мост даёт стабильный маршрут, а короткий путь зависит от направления ветра. В прототипе 0.1 уже работают таймер, перенос и прокачка скорости.

## Запуск

1. Соберите файл места командой `rojo build -o EGGSTRIDE-Playtest.rbxl`. Если у вас архив плейтеста, файл уже внутри. Откройте его через **File → Open from File** в Roblox Studio.
2. Нажмите **Play**. По желанию потратьте стартовые 15 монет на площадке тренировки.
3. В первом забеге подсказка выделит ворота, ближайшее яйцо и инкубатор. После открытия ворот бегите за яйцом. Используйте экранную подсказку или **E**, затем вернитесь к инкубатору и вылупите питомца до конца таймера.
4. Откройте «Питомцы», чтобы увидеть виды по биомам, шансы вылупления и выбрать спутника из коллекции. Тренируйтесь, чтобы открыть яйца дальних островов.

Карта создаётся серверным скриптом при запуске. Для проверки вдвоём используйте режим **Server & Clients**. Обычный запуск в Studio хранит прогресс в пределах сеанса и обходится без публикации и API. В опубликованной игре монеты, скорость, коллекция и спутник сохраняются. Для проверки сохранений используйте [чек-лист Studio](docs/TESTING.md#проверка-сохранений).

## Репозиторий

- `src/shared` — правила раундов, скорость, цены и награды.
- `src/server` — арена и серверная логика.
- `src/client` — интерфейс игрока.
- `assets` — выбранные модели Creator Store.
- `tests` — проверки правил на Luau.
- [ТЗ](docs/PROJECT_SPEC.md), [план разработки](ROADMAP.md), [анализ механик и плейтест](docs/GAME_DESIGN_REVIEW.md), [проверка в Studio](docs/TESTING.md), [источники моделей](docs/ASSETS.md).

Для разработки используйте `rojo serve` или соберите place командой `rojo build -o EGGSTRIDE-Playtest.rbxl`. Для тестов правил запустите `luau tests/rules.luau tests/profile.luau`.
